Робота

Для гри файл не обовʼязковий: без нього картка покаже живу гру, а кнопка Play відкриє її на весь екран.

Інші мови цього відео (для озвучки і перекладу)

Профіль

Тексти сайту. Зміни підуть у наступну публікацію.

Інструменти

Тягни рядок за ⠿, щоб змінити порядок. Клікни на квадрат або перетягни на нього картинку, щоб замінити іконку (PNG, JPG, SVG, WebP).

Дозвіл на публікацію

Кнопка «Опублікувати» зберігає твої роботи прямо в репозиторій сайту. Для цього GitHub видає їй ключ. Робиться один раз у цьому браузері, ключ ніде, крім нього, не зберігається.

  1. Створи ключ. Форма на GitHub уже заповнена.Відкрити GitHub
  2. Repository access: вибери Only select repositories, а в списку .
  3. Унизу сторінки натисни Generate token, скопіюй ключ і встав сюди.

Пароль від GitHub сюди не вводь. Ключ довгий і починається з github_pat_.
